# Aorus Ambient Light (Adaptive Backlight Sync)

Утилита адаптивной синхронизации подсветки экрана (Ambilight) для ноутбуков **Gigabyte Aorus 15 (9KF)** и совместимых моделей с 3-зонной клавиатурой и контроллером ITE RGB Fusion.

---

## Возможности

- **3 независимые зоны клавиатуры:** Левая (WASD), Центральная и Правая (Numpad) адаптируются под цвет соответствующих частей дисплея в реальном времени.
- **Светодиодная полоса (Lightbar):** Синхронизируется с доминантным цветом кадра через аппаратные откалиброванные пресеты.
- **Высокая плавность и скорость:** Захват с частотой 50 FPS с минимальным потреблением ресурсов процессора (< 1% CPU).
- **Плавные переходы (Slew-rate limiting):** Мягкое перетекание цветов без резких скачков и мерцания при смене сцен в играх и фильмах.
- **Алгоритм Vibrant Peak Weighting:** Отсечение темных рамок, панелей задач и неактивных областей, выбор главного насыщенного оттенка сцены.
- **Аппаратная калибровка:** Коррекция баланса каналов для предотвращения искажений в теплых и пастельных тонах.
- **Работа параллельно с Gigabyte Control Center:** Не конфликтует с управлением вентиляторами, режимами батареи и производительностью.
- **Компактность:** Легковесный исполняемый файл без сторонних тяжелых библиотек и зависимостей.
- **Интерфейс:** Темная панель управления с предпросмотром зон в реальном времени, сворачиванием в системный трей и автозапуском.

## Использование и запуск

### Запуск готового приложения
Запустите файл `AorusAdaptiveLight.exe`. Программа появится в системном трее возле часов.

### Сборка из исходников
Для сборки не требуется Visual Studio — используется встроенный в Windows компилятор C#:
Запустите `build.bat` или выполните команду:
```cmd
C:\Windows\Microsoft.NET\Framework64\v4.0.30319\csc.exe /nologo /t:winexe /optimize+ /platform:anycpu /codepage:65001 /r:System.Windows.Forms.dll /r:System.Drawing.dll /out:AorusAdaptiveLight.exe AorusAmbientLight.cs
```

## Настройки в приложении

1. **Яркость подсветки:** Регулировка общей мощности свечения клавиш и световой полосы.
2. **Плавность смены кадров:** От динамичной реакции для шутеров до мягкого перехода для фильмов.
3. **Насыщенность цветов (Vivid):** Усиление глубины цвета для темных сцен.
4. **Режим Lightbar:** Выбор между общей атмосферой кадра и нижней кромкой экрана.
5. **Автозапуск:** Возможность автоматического старта вместе с загрузкой Windows.
